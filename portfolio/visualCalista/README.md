# Calista (Калиста)

**Calista** — российский бренд женской одежды, ориентированный на комфорт, практичность и актуальные тренды.

> Дочерний бренд компании Charuel.

## 📌 Основная информация
| Характеристика | Описание |
| :--- | :--- |
| **Год основания** | 2010 |
| **Стиль** | Романтичный, мягкий (в отличие от более элегантного Charuel) |
| **Производство** | Собственное производство с современным оборудованием |
| **Где купить** | Интернет-магазин [calista.ru](https://calista.ru), розничные магазины в РФ |

## 👗 Что предлагают
- Капсульные коллекции (около 12 в год).
- Базовые вещи на каждый день.
- Сезонные линейки: верхняя одежда, праздничный гардероб, натуральный лён, вязаный трикотаж, деним.

## 🧵 Особенности
- **Посадка:** лекала разрабатываются с учётом особенностей фигуры российских женщин.
- **Ткани:** преимущественно натуральные материалы (хлопок, вискоза), которые пропускают воздух, отводят влагу и не выгорают.
- **Производство:** собственная база позволяет быстро реализовывать дизайнерские идеи.

## 💭 Философия
Бренд создан для женщин с активной жизненной позицией. Философия — **помогать оставаться собой даже в плотном графике**, сочетая темперамент и деловой этикет. Вещи легко комбинировать между собой из сезона в сезон.
